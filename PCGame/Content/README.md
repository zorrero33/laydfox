# Unreal Content Layout

Esta carpeta define el destino de assets. No se añaden paquetes con licencia desconocida.

- `Environments/Hospital`: alas, habitaciones, consultorios, puertas, mobiliario.
- `Environments/Sublevel`: túneles, generador, salas técnicas y vigilancia.
- `Characters/Alma`: malla infantil, esqueleto, rig facial, ropa, materiales y animaciones.
- `Characters/Porter`: celador, esqueleto, materiales y animaciones.
- `Characters/NPC`: Daniel, Lucía, personal y pacientes.
- `Creatures`: entidades y variantes.
- `Audio`: ambientes, voces, pasos, MetaSounds y música.
- `UI`: menú, diario, mapa, inventario, subtítulos, pausa y accesibilidad.

**Bloqueo de publicación:** cada recurso debe aparecer en `../Docs/ASSET_REGISTER.csv` con licencia y atribución verificadas. Los modelos de catálogo Jutsu importados en la escena de referencia tienen licencia individual no expuesta y no se consideran aprobados para una distribución comercial.
